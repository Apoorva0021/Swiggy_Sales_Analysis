# Multi-Page Analytics Dashboard

Hello Sir/Mam Thanks for stopping by. 

This repository contains the full end-to-end Power BI report I built. I spent a lot of time working through raw order and sales datasets, cleaning up messy entries, and designing a comprehensive, multi-page dashboard to get a 360-degree view of how the business is performing.

Instead of squeezing everything onto a single crowded page, I structured this into multiple dedicated dashboard pages (Executive Overview, Regional Sales, Customer & Order Breakdown). This way, anyone—from top management to operations—can easily navigate and get the exact depth of insights they need without clutter.

## What I Wanted to Solve
Working with large transactional data in Excel can get overwhelming. My goal here was to:
* Build a structured, multi-dashboard report that covers both high-level KPIs and granular order details.
* Track **Total Revenue, Profit Margins, and Order Volume** across different operational angles.
* See which product categories and regions are driving the most growth.
* Provide seamless navigation across pages with dynamic filters so users can dig deep into specific dates or categories effortless.

## What I Did & Learned
1. **Multi-Page Architecture:** Designed dedicated analytical views to ensure complex data remains intuitive, clean, and easy to read.
2. **Data Prep & Cleaning:** Pulled in raw order datasets, cleaned up missing values, and created structured data models using Power Query.
3. **DAX Measures:** Wrote custom DAX formulas to calculate key metrics like Average Order Value (AOV), sales growth trends, and profit margins.
4. **User Experience:** Carefully selected charts, KPI cards, and dynamic slicers for smooth cross-filtering between pages.

## Tools Used
* **Power BI Desktop** (Data Modeling, Multi-Page Layouts, DAX, Interactive Visualization)
* **Excel / CSV** (Raw Order & Customer Data)

## What's inside this Repository?
* `Dashboard.pbix` — The original Power BI file with all dashboard pages (you can download and explore it!).
